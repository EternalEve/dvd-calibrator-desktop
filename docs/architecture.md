# 架构决策与几何约定

日期：2026-11-03；阶段：A。

## 运行时与复用边界

使用 C# / .NET 10；Core 和 CLI 不依赖 WPF、浏览器或 Python。后续 Windows 桌面界面使用 WPF。
第一阶段直接编译 `third_party/DiscImageStudio/DvdTrackGeometry.cs`，不另写生产几何。
它是上游 Core 中可独立编译的源文件，不拉入上游界面、刻录或编码依赖。

基准提交、路径和文件字节哈希记录在 `upstream.lock.json`。来源：
[上游几何](https://github.com/JiaFeiMiao-K-Cat/DiscImageStudio/blob/374c0630326ea61be9adca8d7de3c96f083c00df/src/DiscImageStudio.Core/DvdTrackGeometry.cs)。
升级必须显式替换文件、更新锁及 CHANGELOG，运行独立对照与记录适配回归。
生产代码保持一个几何实现；测试单独以复合 Simpson 积分和二分法作为数值参照。

## 单位、坐标和有效域

- 内部半径、轨距、轨长：mm；输入通道位长：nm，乘 `1e-6` 转 mm。
- 角度：rad，不折回到一圈；界面/CLI 的度数仅在边界转换。
- 坐标：从记录面观察，x 向右、y 向上，CCW 正、CW 负，角零在右侧。
- SVG/栅格 y 向下，仅在渲染时翻转 y。照片镜像、EXIF 和观察面转换在阶段 B 显式处理。
- 首版要求 `startLba=0`、相同扇区总数、完整数据映射。前向模型允许 G 与 A 位长不同。
- 包装器拒绝 `[ri,ro]` 外半径与 `[0,1]` 外进度，不暴露上游延拓或夹取接口。
- 工程检查 `7.5 <= ri < ro <= 60`、`0 < N <= 3000000`。这是本工具的工程范围，不是介质合格认证。

## 模型

```text
B = N * 38688
L = B * b_nm * 1e-6
x = (r-ri)/(ro-ri)
p(r) = p0 * (1 + c1*x + c2*x^2 + c3*x^3)
L = integral sqrt(1 + (2*pi*r/p(r))^2) dr
u(r) = s(r)/L
theta(r) = direction_sign * integral 2*pi/p(r) dr

u = u_A(r)
rg = inverse_u_G(u)
phase = theta_A(r) - theta_G(rg)
alpha = psi_source(rg) + phase + beta
```

`p0` 由总轨长约束求解，不是独立的第四个自由形状参数。上游检查端点及内部极值的轨距正值，
采用受控积分、分段单调反插值；分辨率不足时抛错。局部查表角误差目标在上游为 `5e-10 rad`，
这不是相机或实盘精度。完整公式与方向适配以阶段验收和独立积分对照为准。

本工具阶段 A 的工程验收预算：单模型累计角误差不超过 `2e-8 rad`、反映射半径误差不超过
`2e-11 mm`（限定测试矩阵）；两模型相位差不超过 `4e-8 rad`。58 mm 处后者对应弧长
约 `2.32e-6 mm`，远小于后续照片标注尺度。测试预算不等同于对任意系数的误差定理。

## 图案与预测

解析标靶 `half-disc` 的明暗由源角度上/下半盘决定；`radial-cross` 由源 x/y 到轴的距离与线宽决定。
图案定义和生成参数一起进入快照哈希。它们不是上游 `target_slim.png`，不冒充其圆环或灰阶边缘。
`ForwardModel` 返回同一数据位置的源半径、累计相位与边界坐标；栅格渲染从输出点反查源图案。

SVG 使用均匀径向采样并报告最大相邻累计角差，超过 pi/8 不画连接线。该局部检查不能证明
点间没有频率过零或高速绕行；后续候选求解还需自适应采样、留出数据与实盘证据。
PGM 为低分辨率点采样，仅供软件示例，不能由其视觉效果判定候选可以进入精调。

## 输出发布

计算产物先写到目标同级的随机暂存目录，取消或失败时只清理该目录，完成后通过目录移动发布。
既有目标一律拒绝，包含并发任务抢占同一输出路径的情形。暂存目录与目标同级以避免跨卷复制。
生成快照和观测通过内容哈希绑定；更改输入需要重新计算结果，不能保留脱离对象的确认状态。
