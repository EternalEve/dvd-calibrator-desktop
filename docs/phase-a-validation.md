## 数值参照与测试矩阵

生产几何直接复用固定上游的 Gauss-Legendre 积分、分段插值与求根逻辑。
独立参照使用补偿求和的复合 Simpson 积分，分别以 8192 与 16384 小区间检查收敛，
以二分法求 p0 与半径；不调用生产积分、根求解或查表接口。

覆盖：

| 类别 | 检查 |
| --- | --- |
| 基础量 | 38688 channel bits/sector、nm→mm、名义轨距数量级与独立薄轨近似 |
| 模型 | 零系数；`(.02,-.03,.015)`；`(-.15,.2,-.05)`；`(-1.1,.7,.1)` |
| 条件 | CW/CCW、133.3/133.33 nm、不同容量、输入侧与实际侧均非零系数 |
| 映射 | r→u→r、u→r→u、256 分段单调性、端点、G=A 恒等 |
| 正向 | 源半径与相位差对照独立数据进度计算、整体转角、多圈保留 |
| 失败 | 内部轨距非正、NaN/Infinity、非法方向、超域半径/进度、非零起点、容量不匹配 |

验收预算：单模型角差 `2e-8 rad`、反映射半径差 `2e-11 mm`、两模型相位差 `4e-8 rad`。
