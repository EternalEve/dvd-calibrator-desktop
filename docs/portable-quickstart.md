# Windows 便携版 0.7.1

完整解压 ZIP 后，双击 `DvdCalibrator.App.exe`。当前包适用于 Windows x64，自带 .NET / WPF 10.0.7 运行时，无需先安装 .NET SDK 或桌面运行时。请保留整个目录，不要只复制 exe。

## 开始使用

桌面默认使用深色模式，工具栏、输入框、照片工作区和预测图采用统一配色。原始照片不做反色或亮度调整。

1. 初次体验点击“载入拟合演示”，再点“拟合描线”。示例是软件合成图。
2. 两盘演示点“两盘合成演示”，等待创建后拟合第二张、检查完整曲线并确认候选，再检查两盘一致性。
3. 实际任务打开冻结的生成快照并导入原始照片，标外缘与孔缘、计算并确认矫正，再描线或分析已知半盘。
4. 单盘用“保存为新任务包”保存 `.dvdphoto`；关联两张盘时用“保存两盘任务”保存 `.dvdcal`。均需新文件名。

计算期间可以取消，原有已完成结果保留；关闭窗口前请等待计算或取消完成。未结束的反光遮罩需要“结束遮罩”，或在照片画布按 Esc 放弃，才能切换模式、计算或导出。

源像素点保持原图坐标。滚轮/滑块缩放，右键平移，左键加点/拖点，Delete 删除选中点。原生鼠标、系统对话框与关闭提示的人工验收安排在最后，尚未标记通过。

## 命令行与安装检查

同目录提供 `DvdCalibrator.Cli.exe`，`--help` 列出命令。使用示例（PowerShell）：

```powershell
./DvdCalibrator.Cli.exe demo --out 'D:/DVD工作/新示例'
./DvdCalibrator.App.exe --verify-installation --out 'D:/DVD工作/新自检'
```

输出目录必须尚不存在。自检不打开操作窗口，执行 WPF 离屏 PNG、合成拟合、单盘/双盘保存回读及最终配置导出，结果见 `installation-check.json`。它不能代替原生交互或真实盘验收。

任务和输出另存到可写目录。程序不自动刻录光盘，不修改全局运行时配置，`physicalValidation` 始终保持 `pending`。

## 文件与源码

- `package-manifest.json`：版本、运行时、逐文件 SHA256、源码提交与工作区变化标记。
- `source.zip`：与本包一起生成的完整对应源码，包含尚未提交的变更；解压后按其 README 构建。源码、构建工具和许可证随包交付。
- `LICENSE` / `THIRD-PARTY-NOTICES.md` / `licenses/dotnet/`：项目、上游和运行时许可证。
- `samples/`：明确标记为 synthetic 的 CLI 软件检查输入。

当前只完成本机隔离运行时与中文含空格路径检查；无 .NET 的全新 Windows 环境检查、原生交互验收和真实盘盲测分别保留待验收状态。便携包未包含上游刻录/ISO 生成器，标靶生成仍按固定 DiscImageStudio 契约执行。
