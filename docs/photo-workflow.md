# 照片工作流（0.3.0）

## 启动与输入

```powershell
dotnet run --project src/DvdCalibrator.App -c Release
dotnet run --project src/DvdCalibrator.App -c Release -- --demo
```

打开第一阶段冻结的 `generation.json`，再导入对应实体盘的**记录面照片**。
支持合成和带完整附件的外部快照；照片支持 PNG/JPEG/BMP/GIF/TIFF，动图/多帧只取第一帧。
原始文件保持字节不变，按 EXIF 1–8（含镜像）定向成原尺寸 RGB24 PNG，不缩小。
文件上限 100 MB、4000 万像素、单边 30000 像素。

会话显式记录观察面为 `recording-side`，不从径向线弯曲猜测观察面；额外标签面镜像暂未支持。
RGB24 用于图像分析，不是光度标定或 RAW 数据；原始文件仍完整保留。

## 标注与矫正

1. 模式选“实体外缘”，沿最外缘标 8–16 点；选“真实中心孔”，沿贯通孔缘同样布点。
2. 覆盖四周，不选数据区、夹持环或桌面阴影。左键加点/拖点，Delete 删除选中点。
3. 滚轮或滑块缩放，右键平移，“适合窗口”恢复视图。点始终保存为定向后原图像素。
4. 点击“计算联合矫正”，核对橙色轮廓与正视预览，满意后“确认矫正”。计算可取消。

矫正仅使用名义半径 60/7.5 mm 的实体双圆，不使用图案笔直或十字垂直约束。
退化、共线、局部覆盖不足、孔缘不一致或高残差会拒绝计算并显示原因。
改变轮廓清空旧变换、预览与确认；已描的原始像素点保留，待新变换重新投影。

## 遮罩与描线

选“反光遮罩”，依次点击至少 3 个多边形顶点后“结束遮罩”。Esc 或切换模式放弃未完成的草稿。
此模式的“清空当前标注”移除全部遮罩；其他模式只清空该类点。
遮罩绑定源像素，正视/极坐标图均从定向原图直接反向采样、应用同一遮罩。
灰蓝色表示盘外、孔洞、越出原图或被遮罩区域。

确认矫正后选“主径向线描点”，从内向外沿同一条源径向边界取点。主线为 `line-1`，
另可描明确对侧的 `validation-180`。点序、连续相位拟合、预测叠线和导出见 [描线拟合](trace-fitting.md)。
遮罩和描点不参与双圆计算；修改它们保持几何确认，但会清除旧拟合与候选确认。

极坐标横轴 0°→360°、逆时针（末列不重复首列），纵轴生成内半径→外半径。
盘面内部 y 向上，图像像素 y 向下。上游矩阵原样按
`disc-xy-y-down-to-oriented-source-pixels` 保存，Core 包装器显式转换 y 符号。
不估计镜头畸变，也不能从插值恢复原图缺失条纹。

## 任务包与导出

“保存为新任务包”写 `.dvdphoto` ZIP，包括 `session.json`、`generation/` 下冻结生成快照和附件、
`photo/original` 原始照片、`photo/oriented.png` 定向副本。
已有拟合时另含可选的 `fit.json`，保存候选、诊断和确认。
原有任务包不会覆盖，使用新文件名保存修订；先写同级临时文件再发布。
未保存改动在替换任务或关闭时提示。打开时校验哈希和输入绑定，不依赖原路径。
ZIP 不任意解压到磁盘，拒绝重复/未知条目及过大解压数据。

“导出预览”写指定名称的正视 PNG 与同名前缀 `-polar.png`，不修改原照片。
预览分辨率只用于核对，不等同于原图可分辨率。

## 命令行及验证边界

```powershell
dotnet run --project src/DvdCalibrator.Cli -c Release -- rectify --session fixtures/photo-session-v2.synthetic.json --out artifacts/rectify-001
```

此命令只计算轮廓几何，输出带变换但尚未人工确认的会话 JSON，不加载或认证照片附件。
完整照片/附件验证由桌面任务包执行。现有演示和检查为合成/软件图，不给出实盘成功率。
原生拖点与文件对话框自动验收受窗口捕获超时影响，见 [阶段 B 验收](phase-b-validation.md)。
