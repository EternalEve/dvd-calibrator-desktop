# 双盘模拟验收矩阵（0.6.0）

## 范围与结果

本轮不依赖实盘，执行 54 项有限软件用例：28 个应接受的断言、24 个带指定拒绝原因的断言，以及 2 个独立边界探测。
28 个接受断言全部满足预先设定的真值预算，24 个拒绝断言全部在预期分类下拒绝；边界探测单独列出，不混入成功/拒绝统计。
这不是实盘成功率、置信区间或任意误差条件下的通过保证。

同次接受断言的观测最大值：

| 指标 | 预先预算 | 本次观测最大值 |
| --- | ---: | ---: |
| 精调 ri/ro 最大绝对误差 | 0.00005 mm | 约 3.64×10⁻⁷ mm |
| 最终配置对真值的下一张中心线形状 RMS | 0.1 mm | 约 0.00981 mm |
| 同上最大形状偏差 | 0.25 mm | 约 0.0284 mm |
| 去整体转角后的最大相位偏差 | 0.1 rad | 所有接受断言通过 |

半径数字是位长、容量、方向和形状固定条件下，对已知数值真值的等效补偿误差，**不能解释为相机或实盘的纳米级测量精度**。
报告同时给出粗调参数误差、原图归一化留出误差、描线留出毫米误差和轮廓像素 RMS，避免只看最终小误差。

## 执行与产物

```powershell
./tools/Test.ps1                         # 编译、Core、图像/界面、CLI、完整矩阵
./tools/Test-SimulationMatrix.ps1         # 单独完整矩阵
./tools/Test-SimulationMatrix.ps1 -Quick  # 14 个判定断言 + 2 个边界探测
./tools/Test.ps1 -SkipSimulationMatrix    # 仅常规回归，适合只改界面等情况
```

`-Out NEW_FOLDER` 可指定新输出目录，已有目录拒绝覆盖；Ctrl+C 取消尚未发布的暂存输出。
完整矩阵可能运行数分钟，逐用例输出进度。`-SkipBuild` 仅在已构建对应 solution 后使用。

产物位于新建 `artifacts/simulation-*`：

- `report.html`：范围、预算、逐项结果、失败分类和中文操作建议。
- `matrix.csv`：粗/精调半径、误差、阶段、状态及像素预算，缺失指标留空。
- `matrix.json`：完整场景、种子、真值、已得到的全部参数、像素哈希、诊断及未知异常。
- `examples/`：有界的基准、组合误差、共享轮廓偏差样本图和可恢复 `.dvdcal`。

未知异常记录为 `error`，不算作正确拒绝；错误分类、误差或流程断言不通过时保留全部报告并返回非零退出码。
矩阵验证到最终配置可核对状态，文件导出/工程回读另由两盘任务常规回归验证。

## 固定参数与场景

两组生成条件都使用 ri/ro=24/58 mm，第一张隐藏实际值为 24.003/58.006 mm：

| 条件 | N | b | 方向 | c1 / c2 / c3 |
| --- | ---: | ---: | --- | --- |
| cw-133.3 | 2295104 | 133.3 nm | CW | .02 / -.03 / .015 |
| ccw-133.33 | 2298496 | 133.33 nm | CCW | -.02 / .03 / -.01 |

每组接受场景使用种子 11、29。零噪声场景的两个种子是确定性重复，不作为独立随机总体样本。

| 接受场景 | 注入条件 |
| --- | --- |
| baseline | 已知透视、无额外噪声 |
| pixel-noise | 原图每通道高斯噪声 σ=10 DN |
| click-noise | 精调点击 x/y 独立高斯误差 σ=.25 源像素 |
| contour-noise | 外缘/孔缘点击 x/y 独立高斯误差 σ=.15 源像素 |
| perspective | 更强的已知单应透视，重新联合矫正 |
| masked-gap | 40° 遮挡及掩膜，37–41 mm 低信息缺失带；描点仅取可见边界 |
| combined | σ=8 DN、点击 .15 px、轮廓 .1 px、较强透视和上述遮挡/缺失 |

源图通常为 900×900；低分辨率拒绝项的第二张为 360×360。
实体边缘用 32 点生成，先注入源像素误差，再拟合 H。精调最多取主线 96 点、明确对侧线 48 点，缺失区不伪造点击。
第一张从原图像素独立进行密环分析，P1 冻结为 G1；第二张轨迹按自己的 G1 和实际模型生成并独立拟合。
密环直接受像素噪声影响；当前精调入口依赖人工描点，点击噪声是独立配置，不声称其自动从噪声图中识别中心线。

每组拒绝项：

| 注入错误 | 指定拒绝分类 |
| --- | --- |
| 空白图案、270° 遮挡 | photo-insufficient |
| 把 12 mm 半径当真实孔缘 | photo-contour-mismatch |
| 将 90° 臂误标为对侧 180° | model-mismatch |
| 主线中途换到相反臂 | trace-adjacent-angle |
| 点序反向 | trace-radius-order |
| 描点留在遮罩内 | trace-point-masked |
| 主线只覆盖中间窄区 | trace-coverage |
| 第二张实际 ri/ro 改为 24.0035/58.0068 mm | disc-inconsistent 或 disc-domain-inconsistent |
| 第二张记录冒用 G0 | fine-generation-mismatch |
| 冻结计划后改变第一张观测 | coarse-plan-stale |
| 第二张线宽有效像素不足 | fine-photo-resolution-insufficient |

两项边界探测让两张实体轮廓的标注半径共同偏大 0.1%，不同时移动实际图案像素。
它们预先标记为 `characterize`，只记录观察和真值，不强行宣称必须接受/拒绝。
本次两项通过软件检查且仍在真值预算内，最大中心线误差约 0.00049/0.00070 mm。
这没有证明更大的偏差、错误盘心、镜头畸变或所有共同误差都能被排除。

## 独立参考与判断

轨迹真值使用独立的全长 Simpson 求 p0、8192 个累计 Simpson 小区间及区间内二分逆映射，
未调用生产 `TrackGeometry` 或 `ForwardModel` 来生成轨迹。启动先与 16384 区间的全积分/二分参考比较。
相机投影使用既有、单独经过数值测试的单应包装器，原图采样复用已锁定上游参考 PNG 规则。
生成照片时查密集真值表，不把像素插值当成额外分辨率。

最终候选作为下一张生成补偿，再按独立实际真值计算 257 个半径上的中心线相位，去掉一个整体转角，
用 `r*δα` 统计毫米形状差；最大相位也独立约束为 .1 rad，避免大相位时滥用小角近似。
不逐点加减圈数；第一张结果不进入第二张拟合目标，保留各自连续留出与对侧检查。

## 操作建议与限制

桌面、CLI、密环 HTML 报告和矩阵报告共用 `CalibrationIssue(code,title,action)`。
对遮罩内点、换臂/漏圈、留出失配、分辨率、G0/G1 错配、旧计划和盘间冲突分别给出补拍/补点/核对建议。
提示不会降低原有确认与留出门槛，也不会自动删除点或取消遮罩。

本轮仍未覆盖真实光学亮度、镜头径向畸变、所有几何/轨距形状变化、更多容量及介质/写入设备、完整不确定度传播。
随机噪声仅是明示的高斯模型，没有将这两个种子称为可靠性统计。
原生鼠标/系统文件对话框验收、便携运行时交付及真实盘盲测仍待后续完成；本轮没有操作刻录设备。
