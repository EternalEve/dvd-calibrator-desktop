# 密环与混合观测（0.4.0）

## 使用

```powershell
dotnet run --project src/DvdCalibrator.App -c Release -- --dense-demo
```

演示含完整生成模型、已确认的合成投影、变频半盘条纹、38–41 mm 低对比缺失带，以及 29–33 mm 局部主边界描点。
点击“分析密环 / 混合”。紫色为完整模型预测，蓝色仅连接有效观测片段；缺失带中的模型线不代表测到了条纹。
右侧显示有效比例、拟合半径、相位/图像留出误差及下一张诊断。保存新任务包可恢复原图和全部结果。

“导出密环诊断”在选定父目录新建目录，包含：

- `dense-analysis.json`：全候选参数、极性、片段圈数、误差、拒绝理由和下一张预测。
- `generation.json` / `photo-session.json`：输入身份及观测绑定。
- `local-frequency.csv`：局部谱峰、有符号相位斜率、谱集中度与有效像素/周期。
- `reconstruction.svg` / `next-disc.svg`：第一张边界重建和下一张四臂中心线预测。
- `report.html`：中文报告，可离线打开。

报告没有复制照片；完整原图保存在 `.dvdphoto` 任务包。输出目录及任务包均拒绝覆盖。
当前密环入口在桌面和 Core API 提供，CLI 继续支持既有描线及配置导出命令。

## 受支持输入

必须是当前快照明确记录的 `analytic-disc-xy-v1` / `half-disc`，且对应记录面原图与矫正已确认。
外部源图片、上游其他标靶、解析十字和未确认矫正不自动猜测为半盘。它们仍可使用连续描线入口。
密环拟合固定实际 b、N、方向和轨距形状为生成值，仅搜索 ri/ro；默认 ±0.02 mm，命中边界拒绝支持。
Core `DenseSettings` 可显式设置范围至 ±0.5 mm；桌面暂用默认范围。

混合模式允许一条 `line-1` 局部主边界及可选 `validation-180` 对侧边界，6–600 点即可，
可以只覆盖稀疏区域。点必须有正确的源边界身份、按半径严格增加、相邻转角小于 π/2 且不在遮罩内。
只有主线前 75% 参加优化；对侧整条线留出。每条线保留一个全局整数圈分支，不能逐点改圈或单独旋转。

## 观测、分支与留出

1. 用单应矩阵在原图反向采样，半径范围避开模型端点。按各方向最保守源像素/mm 定步长，最多 1024 个径向样本；不足 64 有效径向像素拒绝。
2. 默认 48 个角度，偶数角度训练、奇数角度留出。RGB 通道由训练角度和内侧 75% 半径的对比选择，之后冻结。
3. 训练角度拟合常量/正弦/余弦角谐波，取得已知半盘的有符号相位。饱和、遮罩、低对比不作为零值填充。
4. 按缺失、相邻相位跳变、近零频率和反向切片。连续片段至少 12 点，保留末侧连续 25% 及全盘外侧 25% 为径向检查；不足训练点的片段不用来拟合。
5. 各片段滑动 Hann 窗计算局部频谱，另存相位斜率。谱峰有有限窗分辨率，不把频谱插值精度当成物理精度。
6. 片段内训练相位差经完整几何的半径灵敏度生成种子，再用有限多起点和稳健相位残差优化。每片段只有一个整圈偏移。
7. 每片段同一通道的原图亮度只允许统一偏置和增益，由训练像素确定；冻结后检查全部奇数角度与径向留出像素。

半盘明暗反转与整体转角增加 π 等价，没有额外证据时同时保留。几何等价的极性分支不应误算为两套不同物理参数。
相位符号来自已知多角度图案关系；缺失处整圈连接是候选模型的分支假设，仍需完整图像和后续证据检查。
若可用径向比例不足 35%、训练相位不足 24 点或缺少局部变频证据，返回 `photo-insufficient`，不编造参数。

## 诊断门槛与下一张

相位训练/留出 RMS 不超过 0.3 rad、归一化图像 RMS 不超过 0.25；混合描线 RMS 不超过 0.35 mm、最大不超过 0.8 mm。
原图每周期至少约 8 像素；越界、搜索截断、片段证据不足、曲线采样不足和图像矛盾均拒绝支持。
像素预算同时检查局部观测频率和完整候选曲线最大斜率，避免滑动窗口漏掉环带端部的高频区域。
这些是当前软件工程筛查值，需要实盘校准，不能当作通用物理保证。

下一张生成模型 G1 使用首个受支持候选，精调靶明确为 0.3 mm 解析十字。每个受支持实际模型 Aj 分别重新计算 `Forward(G1, Aj)`，
在共同有效域去掉整体转角后比较曲线形状。候选差异大于 0.2 mm 返回歧义；十字臂间径向间隔至少 8 源像素、
法向线宽至少 2 源像素才通过当前分辨率筛查。报告保留精确 G1 和靶定义，不创建 ISO。

`dense-review` / `next-disc-review` 只表示有可核对的候选，**不等于 `coarse-ready` 或实刻通过**。
有限起点、有限候选不是穷尽搜索或完整不确定度传播；未观测区、轮廓误差、镜头畸变、局部光照反转和光学成像模型待验证。
密环诊断不直接送入旧描线确认/工程导出流程。0.5.0 可据受支持候选创建独立的 [第二张计划](two-disc-workflow.md)，
使用固定上游原图重新计算其真实名义线宽及完整预测；本页所述 0.3 mm 解析十字仍仅是阶段 D 诊断靶，两者不会混用。
