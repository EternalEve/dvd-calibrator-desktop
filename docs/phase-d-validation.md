- 只有绿色通道含强证据，验证通道选择；缺失带保留为不同片段，局部相位频率随半径改变。
- 反向 CCW、全局明暗反转、两个极性分支、6–600 点局部描线的联合拟合和错误边界拒绝。
- 频率过零/反向样本 ri=24.01 / ro=57.99 mm，保留两种斜率符号并恢复受支持候选。
- 专门只破坏留出角度的图像，训练仍吻合，原图留出误差拒绝支持；不通过额外亮度自由度消除矛盾。

- 密环结果随 `.dvdphoto` 保存恢复、导出报告/下一张 SVG、拒绝覆盖、修改遮罩失效。
- 离屏 WPF 检查诊断文字、紫色完整预测和至少两条独立观测片段，生成桌面截图。

## 保留的限制

本次针对明确解析半盘靶实现阶段 D 首个可验证闭环；没有把任意源图片或上游所有标靶包装成通用自动密环入口。
密环只调整两个半径，轨距形状保持生成值，形状失配返回诊断；连续描线入口保留阶段 C 的可选高阶拟合。
当前默认范围有限、不宣称穷尽所有整圈分支，也没有完整参数/轮廓置信区间。
候选对下一张的间距/线宽预测是当前照片分辨率下的工程筛查，不能直接给出 `coarse-ready`、`fine-ready` 或两张盘成功率。
真实照片、物理 DVD 刻录、上游标靶一致性、完整两盘关联及原生鼠标/文件对话框自动验收仍需后续工作。
原生窗口捕获失败的历史限制见阶段 B 验收；本次界面验证是离屏渲染及任务 API 闭环。
